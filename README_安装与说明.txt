中文下载文件名自动解码 · Chrome 扩展 v1.0.0
======================================

一、作用
ChatGPT 网页版有时在对话中显示正常中文下载名称，但保存到电脑后，
文件名变成 %E4%B8%93%E5%88%A9... 这样的百分号编码。
本扩展会在 Chrome 确定下载名称时，对合法的 UTF-8 百分号编码文件名
进行解码。不会更改文件内部内容，也不会对文件进行重新下载。

例如：
%E4%B8%93%E5%88%A9%E5%88%9D%E7%A8%BF_%E6%8A%80%E6%9C%AF%E6%9D%A5%E6%BA%90%E6%89%B9%E6%B3%A8%E7%89%88.docx
-> 专利初稿_技术来源批注版.docx

二、安装（Windows / Chrome）
1. 将 ZIP 压缩包解压到固定目录（例如 D:\ChromeExtensions\filename-fix）。
2. 打开 Chrome，在地址栏输入 chrome://extensions 回车。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择含 manifest.json 的解压后文件夹。
5. 之后重新下载一个此前文件名出现百分号编码的文件测试。

三、行为与注意事项
- 只修改可以完整解码、且结果包含非 ASCII 字符的文件名。
- 正常中文、正常英文文件名不做任何处理；乱码/不完整 UTF-8 也不强行处理。
- 如遇重名文件，Chrome 会添加序号，不自动覆盖旧文件。
- 无远程服务器、无联网权限、不上传文件、不会读取文件内容。
- Chrome 为下载命名扩展提供 downloads 权限；浏览器可能显示“管理下载”的权限提示。
- 为避免绝对路径或恶意目录穿越，修复后的文件名仅含基本文件名；
  如果其他扩展或下载工具在下载前设定了特殊子目录，此扩展可能恢复到默认下载目录。
- 如果安装了其他重命名下载文件的扩展，可能出现优先级冲突。
- 仅影响安装后的新下载；不会自动重命名历史文件。
- 此方案规避下载命名问题，不修复 ChatGPT 服务端可能存在的文件名编码问题。

四、卸载
打开 chrome://extensions，找到“中文下载文件名自动解码”，点击“移除”。
